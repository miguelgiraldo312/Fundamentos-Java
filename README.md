# Fundamentos de Java — Práctica de Aprendizaje #1

Repositorio con ejercicios prácticos desarrollados para afianzar lógica de programación, estructuras de control, manejo de entrada por consola y modularización mediante métodos estáticos.

## Estructura del Proyecto

Los programas se encuentran organizados dentro del paquete `proyecto1` (`src/main/java/proyecto1/`):

* **`Calculadora.java`**: Calculadora básica por consola que realiza operaciones aritméticas fundamentales utilizando estructuras condicionales y métodos separados por operación.
* **`ParImpar.java`**: Programa que evalúa números ingresados por el usuario para determinar si son pares o impares mediante el operador módulo (`%`) y validación en métodos estáticos.
* **`PromedioNotas.java`**: Cálculo de promedio académico a partir de múltiples calificaciones ingresadas por consola, aplicando ciclos y validación de resultados.
* **`ValidarUsuarioClave.java`**: Sistema de validación de credenciales con un límite máximo de 3 intentos. Implementa constantes (`private static final`), ciclos `for`, control de flujo con bandera booleana y `break`, cálculo de intentos restantes y separación de responsabilidades entre la validación de credenciales y la salida por consola.
